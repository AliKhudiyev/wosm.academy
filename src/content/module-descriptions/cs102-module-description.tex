\section{Module Overview}
This module shows how a computer is built, starting from nothing more than
switches that are on or off. It follows the module leader's book
\textit{A Student's Computer Architecture Book I}: you first learn the
fundamentals of digital design, and then use them to build a working 8-bit
computer, the DX8, piece by piece.

The first part covers the foundations: numeral systems, Boolean algebra and
Boolean functions, logic gates, combinational circuits and sequential circuits,
including finite state machines, latches, flip-flops, counters and timing. The
second part puts these building blocks together. You design an instruction set
architecture, build an arithmetic logic unit, registers and random access memory,
and connect them with a stepper and a controller into a multi-cycle processor that
fetches, decodes and executes instructions.

The module is for anyone who is curious about how computers really work, and no
prior knowledge of electronics is needed. Digital Design and Computer Architecture
II (Semester 3) continues with real instruction set architectures, memory systems,
input/output and processor performance.

\section{Aims}
\begin{itemize}
  \item Show how a working computer is built up from logic gates, one layer of
        abstraction at a time.
  \item Give a mathematical foundation in Boolean algebra for describing,
        designing and simplifying digital circuits.
  \item Develop practical skill in designing, simulating and testing combinational
        and sequential circuits.
  \item Give you the understanding and confidence to design and build computing
        devices of your own.
\end{itemize}

\section{Learning Outcomes}
After completing this course, you will be able to:
\begin{enumerate}[label=LO\arabic*.]
  \item Represent numbers in positional numeral systems, in particular binary,
        octal and hexadecimal, and convert between them.
  \item Manipulate Boolean expressions with the laws and theorems of Boolean
        algebra, derive canonical sum-of-products and product-of-sums forms from
        truth tables, and simplify Boolean functions with Karnaugh maps.
  \item Implement Boolean functions with logic gates, including universal gate
        sets, and design and analyse combinational circuits such as multiplexers,
        decoders, encoders, adders and comparators, including their propagation
        and contamination delays.
  \item Model sequential behaviour with Moore and Mealy finite state machines,
        build latches, flip-flops, registers and counters, and explain the setup
        and hold time constraints of sequential circuits.
  \item Explain the Von Neumann architecture and the role of an instruction set
        architecture, and design an arithmetic logic unit, a register file and
        byte-addressable memory from basic components.
  \item Explain how a processor executes instructions in fetch, decode, execute and
        load stages, compare single-cycle, multi-cycle and pipelined designs, and
        build and program a working multi-cycle 8-bit computer in a circuit
        simulator.
\end{enumerate}

\section{Teaching and Learning Methods}
The module is self-paced. All materials are provided on Moodle. The module follows
the module leader's book \textit{A Student's Computer Architecture Book I}. Each
unit has a lecture and exercises in which you build and test the circuits of the
unit in the Logisim-evolution circuit simulator; circuit files for the examples in
the book are provided. Verilog models of many of the circuits are also available
for students who want to go further.
Each week has two lectures, a central exercise with worked examples, and a tutorial
in which the solutions of the week's exercise sheet are discussed.

\section{Assessment}
Your understanding and knowledge of the concepts presented will be assessed
through quizzes, a circuit-design project and the final exam. In the project you
build the DX8 computer, or an extension of it, in Logisim-evolution and run your
own programs on it. Any permitted support materials will be provided during the
examination; no additional aids or resources are allowed.
